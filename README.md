# DocBuilder

Serversiz ishlaydigan hujjat skaneri (Expo, React Native). Hamma narsa telefonda saqlanadi.

## Ishga tushirish

```bash
npm install
npx expo start
```

Terminaldagi QR kodni telefondagi Expo Go bilan skan qiling (kompyuter va telefon bitta Wi-Fi'da bo'lsin).

## Tuzilma

- `src/app/` — ekranlar (expo-router)
- `src/components/` — umumiy komponentlar
- `src/theme/` — ranglar, shrift, oraliqlar, yorug'/qorong'i rejim
